# core/ — движок правил на C#

Те же правила, что у трекера (`tracker/src/engine`), для игры на Unity (Г8). Без `UnityEngine`, без случайности «из воздуха»: генератор с зерном передаётся в `EngineContext`.

## Проверка

```
dotnet run --project Tests
dotnet run --project Tests -- polygon    # полигон движения: открыть core/polygon/polygon.html в браузере
dotnet run --project Tests -- jumps      # прыжки тел и фигурок в кадрах по всем сценам полигона (должно быть 0)
```

Главный тест — эталон v29: 400 замороженных сценариев из `shared/golden/scenarios.json` отыгрываются и сверяются с `shared/golden/golden.json` строка в строку — заголовок и строки журнала, тон, все поля отрядов. Трекер проходит тот же эталон, значит, обе реализации считают одинаково.

Почему совпадает до символа: JavaScript округляет `Math.round(2.5)` в 3, а C# `Math.Round(2.5)` — в 2 (к чётному); печатает `415`, а не `415.0`. Поэтому все числа идут через `Js.Round`, `Js.R1` и `Js.Num`. А генератор mulberry32 — побитово тот же, что в `util.js`.

Карта 6а сверяется так же, но бит в бит: `tracker/tests/mapcases.mjs` отыгрывает генераторы (19 вариантов × 3 зерна), сохранение и битые сохранения, кисти, строй и местность под отрядом, путь по клеткам, панику и участки стен (нарезка, удары, проломы, пересборка); результат заморожен в `shared/golden/map.json`. `MapCases.cs` повторяет то же на C# и сравнивает поле за полем — при расхождении печатает путь до него, например `geo[3].pairs[7].gap`. Синусы и `hypot` из .NET расходятся с Node в последнем бите, поэтому карта считает их через `JsMath`.

Шаблоны отрядов — тоже: `tracker/tests/templatecases.mjs` прогоняет названия отрядов из сохранений и крайние случаи (тип войск, шаблон), правки шаблонов из партии в любом виде, в каком они могут прийти (числа строкой, null, списки, мусор), и итоговые профили по фракциям; результат заморожен в `shared/golden/templates.json`, `TemplateCases.cs` сверяет. Правки из партии `Templates.NormalizeOverrides` принимает деревом, как после разбора JSON (словари, списки, строки, числа), и читает числа как унарный плюс JS: `"90"` → 90, `""` → 0, `"abc"` — выброшено.

## Как подключить к Unity

В `game/Packages/manifest.json` добавить строку в `dependencies`:

```json
"com.journal.battlecore": "file:../../core/Package"
```

Unity скомпилирует исходники сама под свой профиль .NET. Папки сборки `bin/` и `obj/` лежат вне `Package/`, поэтому Unity не увидит движок дважды.
