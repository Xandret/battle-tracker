# game/ — игра на Unity

Здесь будет проект Unity (этап И2 в SPEC: Вторая битва при Пикшарпе за одним компьютером).

## Как создать проект (делает Алекс — нужен вход в аккаунт Unity)

1. Установить Unity Hub, войти в аккаунт, поставить последнюю LTS-версию редактора (Hub предложит сам).
   Условия бесплатной лицензии — проверить в Hub.
2. В Hub: New project → шаблон **2D (URP)** → расположение — эта папка `game/`, имя проекта — `.` не выйдет,
   поэтому создать проект с любым именем во временной папке и перенести его содержимое (Assets/, Packages/,
   ProjectSettings/) сюда, в `game/`.
3. Открыть проект один раз, закрыть — Unity создаст служебные папки (они в .gitignore).

Правила боя в игру приходят из `core/` (C#-библиотека без Unity) — подключение описано в core/README.md.
